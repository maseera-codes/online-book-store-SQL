# Online Book Store — SQL Data Analysis

A MySQL project that analyzes an online bookstore's sales, revenue, and customer purchasing behavior using SQL.

## Project Overview

In this project, I designed a relational database for an online bookstore and used SQL to answer business questions related to books, customers, orders, sales, and revenue.

The project demonstrates practical SQL skills including database design, table relationships, JOINs, filtering, aggregation, grouping, and business analysis.

## Database Schema

The database contains six related tables:

- **authors** — Stores author information.
- **customers** — Stores customer details.
- **books** — Stores book details, prices, and stock.
- **orders** — Stores customer orders and order status.
- **order_items** — Stores the books and quantities included in each order.
- **payments** — Stores payment details and payment status.

### Table Relationships

- `authors` → `books`
- `customers` → `orders`
- `orders` → `order_items`
- `books` → `order_items`
- `orders` → `payments`

Primary keys and foreign keys are used to establish relationships between the tables.

## Business Questions & Analysis

The project answers the following business questions:

1. Which books are available along with their authors and prices?
2. Which books are priced above ₹500?
3. How many books does each author have?
4. What are the top 3 best-selling books by quantity?
5. How much revenue did each book generate?
6. What is the total revenue from all order items?
7. What is the total value of each order?
8. How much has each customer spent?
9. Who is the highest-spending customer?
10. Which customers have not placed any orders?
11. Which books have never been ordered?
12. What is the revenue generated from completed orders?

These questions were answered using SQL JOINs, filtering, aggregation, GROUP BY, ORDER BY, and LIMIT.

## Key Insights

- Identified the top-selling books based on quantity sold.
- Compared revenue generated by individual books.
- Identified the highest-spending customer.
- Identified customers who have not placed any orders.
- Identified books that have never been ordered.
- Calculated revenue generated from completed orders.

## How to Run

1. Install MySQL and MySQL Workbench.
2. Open `online_book_store.sql` in MySQL Workbench.
3. Execute the script to create the database, tables, and sample data.
4. Run the analysis queries to explore the bookstore data.
